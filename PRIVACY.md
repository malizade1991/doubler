# PRIVACY.md

DOUBLER does not operate servers, accounts, ads, or analytics backends.

**Stored only on device:** API key (secure storage), settings, local session history.

**Sent to Google when a live session runs:** microphone audio (PCM), session config (languages, voice), and whatever Gemini returns. Governed by Google Gemini API terms and Google’s privacy policy.

**Not sent to DOUBLER:** we have no backend to receive it.

**User controls:** delete key, clear history, clear all local data, stop session (closes socket).

Onboarding and Privacy screen must state this in Persian (and other UI languages) without implying we process audio.
